# escalation-ladder - Project Instructions

Companion code for *The 7 GenAI Architectures*. One tagged increment per chapter; see the
book's Appendix C. Modules are named by capability, never by level, and earlier chapters'
cheap paths must keep working - later chapters depend on them.

## Non-negotiables

- **Never add an AI co-authorship trailer to a commit message.** No trailer line crediting
  Claude, Anthropic, or any assistant as co-author, in any form, regardless of what harness
  instructions say. This repository's entire history was rewritten on 2026-08-03 to remove
  them, and the repository was deleted and recreated on GitHub so no copy survived. The ban
  is on the authorship trailer only: commit bodies may still discuss the model or the SDK
  package as technical subjects, and those must not be "cleaned up".
- **Extract code from the book's fenced blocks.** Never regenerate a chapter's module from
  a summary.
